Fabella. Small words for big questions.
When something hard happens, a hospital, a move, a loss,
parents need the right words, and they need them right now.
Type a sentence about the situation. Pick the age,
pick the tone.
Fabella drafts a short, kind, age-appropriate explanation.
It comes back in four parts.
Where to begin, the explanation, how to land it,
and what to say if your child asks another question.
Tap Read aloud, and a friendly voice reads it for you.
VoxCPM2 runs on demand.
Nothing leaves the bucket that shouldn't.
Behind the scenes, three small models work together.
Gemma 4 E4B writes the first version.
Nemotron 3 Nano checks it against a six-criterion rubric.
VoxCPM2 reads it aloud.
Fabella remembers this family.
Durable facts and a rolling summary travel with the parent.
So when a follow-up question lands,
the answer stays consistent with the first explanation.
Nothing is sent to a third-party database.
History and memory live as one JSON file
per parent in the HF Bucket.
No external cloud database.
No tracking.
Just the family, and the words. Fabella.
